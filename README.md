# Rain Prediction using Machine Learning

## Project Overview

This is a beginner-friendly data science project that predicts whether it will rain tomorrow using historical weather data from Australia.

The project includes:

- Exploratory Data Analysis
- Data Cleaning
- Missing Value Handling
- Feature Engineering
- Machine Learning Model Training
- Model Evaluation
- Streamlit Web App

## Dataset

The dataset used is `weatherAUS.csv`.

```text
RainTomorrow
